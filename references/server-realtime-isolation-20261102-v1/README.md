# Native realtime isolation

An ordinary dungeon relay datagram and native 9C clock used to wait for the economic worker, including ice draw persistence. The frozen ONLINE increment publishes immutable authorized room views after business operations, adds an independent account reader and immediate session fences, and lets foreground work cancel only pending periodic claims. Running work and economic transactions remain serialized. The exact nine-byte 7D0 noop keeps frame and sequence validation.

`source/online` contains the 11-file delta against the parent SHA in source-contract.json; it is not a full runtime. Root collaboration code and old LOCAL migration are outside this change. Deployment config sets 192 connections; the code ceiling is 384. There are no client, schema, item-pool or price changes.

All 19 checks are reused after full parent, source, fixture and interpreter hash verification. The separate 50-account/150-TLS controlled run measured relay P95 14ms, max28ms, ice P95 2266.33ms and clock maxgap1023.97ms. This is one controlled run, not a production A/B or a sustained 50-player guarantee. Natural GUI and combat are untested. Installation acceptance is recorded separately by the release owner.
