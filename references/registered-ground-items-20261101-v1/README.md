# 登记物品的关卡掉落显示与拾取

原入口只接收85个掉落模板，已登记且有原生模型的77010初级魔力药水也被CF/D0拒绝；通用入包分支仍使用早期固定药水占位，并在D2省略实际模板。候选共享模板准入改为复用现有库存登记，保留既有来源描述校验；通用拾取使用服务端已签发行的真实模板、数量，预先编码对应D2，继续复用事务内D3、身份/副本/阶段/距离检查、幂等和冷读。

原客户端112组模型名中另有23组实际返回空模型。修复苹果拼写、Add大小写、旧防具部位引用；缺失字段和错误贴图引用使用现有原生类别模型。武器、上衣、下衣、手套、鞋子继续区分，发型与杂项使用原生袋装类别。最小支持只调整1032000调用97A980时的模型名参数，实际模板、名称、物理状态机及拾取不变。详见[支持说明](HOOK-NOTES.md)。

资格证据覆盖104289个登记/原有模板的CF/D2身份保真、112组原生构造器及2240个D0模式，以及自有SQLite的真实模板/数量、重复请求、伪造身份拒绝、编码失败回滚和冷读。隔离客户端经真实TCP收包验证114个代表模板全部获得非空原生模型，其中额外两例覆盖空模型武器和发型；属于受控显示验证，不声明114个自然掉落来源或完整自然战斗验收。没有新增掉落来源、奖池、概率或经济数值。

此目录归档当前双端父版的精确候选，根目录历史验收源码保持原字节。`source-contract.json`绑定源码与父版；候选未激活，安装状态由发布负责人回执确认。支持需要独立审查及启动器签名交付，Friends兼容配置按实际Friends父版绑定，不能覆盖为LOCAL配置。原始EXE/KOM、抓包、运行日志及数据库不入Git；隔离服务器的定时CF测试入口也不在候选内。

可移植验证：`python -B tools/verify_registered_ground_items.py`、`python -B -m unittest tests.test_registered_ground_items tests.test_ground_model_support`。测试使用合成内存与固定报文体隔离协议性质，真实ABI与图形加载证据独立保留，不把单测模拟写成原生执行。
