# Camilla Force shop and manufacture

Camilla's native starter Mod books were registered but refused by the career-box acquisition policy. This patch admits the 180 original offers only through the owned Camilla shop purchase transaction and uses the native ED price. Manual A/E crafting stays on the original manufacture transaction and now requires a town with Camilla's native menu.

This is a source archive for the V128 runtime parents listed in the source contract. The collaboration main branch does not yet include the released career-box or Change Force registries. Apply these four files to a runtime that matches the source contract and integrate them with their existing dependencies when those reach main.

Three authenticated isolated session tests covered purchase, learning and cold read, replay, rollback, invalid merchant and town, and both manual recipes. The original client purchase writer and reader and manufacture writer were replayed offline. Formal installation and menu operation are pending.
