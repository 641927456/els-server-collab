# 原生机关生成依赖闭包修复

原客户端AI创建环境、替身、核心、花、龙卷、屏障等实体时，较新解码脚本未进入旧采集目录，导致阶段允许列表、初始化身份或该模式HP绑定缺失。当前候选从实际静态编排出发，追踪直接与递归原生生成调用，补齐20个已准入副本模式、36个阶段的60处依赖。包括此前五图十处修复，按最新线上父版选择性整合。

运行增量为5个数据文件；新增9个原生初始化/HP身份和41条精确模式HP绑定。公共开发采集器读取原客户端SHA与明文SHA均匹配的6457条注册NPC原生解码记录。原客户端EXE/KOM、AI、状态机及计时不改。原NPC编排、过门条件、奖励、既有HP行和最新混合玩家/场景召唤实现全部保留。缺失HP沿用已经批准的精确原地图/模式规则，不跨模式复制或填500/5000回退。

60项旧数据拒绝对照、60项真实DungeonRun入口、60项实际双人Application/TLS广播验证通过；动态父实体由真实请求创建，重复请求只回ACK，客机越权与非法混合批次被拒绝，余额不变。晚期阶段采用隔离夹具；不声称自然入场、全程团本通关或多人实战。原8处特殊骑乘声明通过。四个原脚本查找缺口及160个变量参数调用脚本仍是静态分析边界，没有当作通过或新增故障。

此目录按既有协作方式归档精确运行增量，不激活仓库根引擎。source-contract.json绑定私有完整父运行；repair目录保存维护者在原分析目录布局中执行的源采集与测试器，依赖已核的KL解析器、原资源索引和私有运行资料。便携校验：`python references/dungeon-spawn-closure-20261104-v2/verify_contract.py`。

正式安装、Git提交、主干合并分别登记。生产安装事实见installation-summary.json（安装后加入），不包含认证资料、玩家库、运行日志或抓包。
