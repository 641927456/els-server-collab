# Royal Guard storefront restoration

Native machine 163483 was omitted because the catalog builder used only IceHeaterPreView_INT. The ordinary preview supplies its 108 existing reward memberships for 11 character types. This batch restores that exact machine at the established 30 ED price and old-machine 10% series / 90% common policy. Four later character machines and sealed 900167 remain unchanged.

The six private runtime data files are distributed through the SHA-pinned resource in resource-lock.json, separate from source Git. source-contract.json records each original and resulting SHA. The tools folder preserves the development-layout builder and isolated economic tests actually executed in G:/els; it does not claim a standalone checkout has the private runtime.

Validation covers all 15 character listings, 11 purchases/draws, rollback, ownership, replay and cold reads, plus one original native reader/classifier case. Deployment and public TLS results are recorded separately after acceptance. No natural GUI claim. No credentials, player databases or raw logs are included.
