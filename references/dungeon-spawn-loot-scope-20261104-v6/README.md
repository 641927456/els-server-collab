# 副本生成依赖与掉落校验修复

机关生成允许列表更新后，原掉落指纹对整张图作比较，导致已安装版本的 Source loot source/build scope 校验失败，能够打断怪物退场处理；继续补齐生成依赖也会使另外两类掉落目录失效。修复只从掉落指纹中排除阶段 allowed_summons。动态机关仍由现有生成入口强制 no_drop=True，掉落来源仍须匹配当前静态对象、source_index、模板及资格；所有静态怪物、跳转、图来源和其他字段继续受校验保护。

source 保存累计 14 个文件（12 个运行文件、2 个开发工具），其中 7 个生成依赖文件与同级 v5 归档完全相同。三类掉落 JSON 仅更新 route_scope_sha256，加载器只更新 DATA_SHA；池、概率、数量、道具描述、旧回执上下文和存档格式均不变。候选基于实际 native-modern-ice-cubes-points-20261104-v1，保留父版其他增量。

三类实际目录分别覆盖 53／33／22 图；独立内存变更验证机关列表更新可通过，静态群组、跳转和来源变化均被拒。七个自有隔离数据库场景验证退场、生成、拾取、重复请求、错误身份拒绝、编码失败回滚及冷读；五个首次成功用例直接复用，旧夹具错误保留并仅重跑受影响用例。便携回归还覆盖 128 组机关列表和静态权限字段。原 235 项生成域／双人 Application/TLS 及最新父版两项 TLS 结果见 v5，相关生成载荷逐字节保持。

不声称完成自然全副本通关。35870 中 12578 的缺失枚举及 12582 原 Lua 来源仍未补齐，未猜别名或替代行为。六个原档缺失 Lua 的不可执行入口复核见 v5。

执行 verify_contract.py 与 test_loot_scope.py 可在不持有游戏资源时核归档及行为；repair 为原私有分析布局下的复现脚本，不携带客户端、原始日志、抓包或玩家库。本归档不激活根引擎、不安装服务器、不合主干；实际安装由项目指定发布负责人核当时父版后完成。
