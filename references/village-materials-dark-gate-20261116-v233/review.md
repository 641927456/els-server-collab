# 发布接收审查

当前服务端业务为 V231，签名支持组件为 V232。11 个候选文件的父 SHA、候选 SHA，以及 12 个相关依赖均逐一核对相符。已直接读取来源会话的人类安装指令；这批不授权本机客户端验证。

逐个审阅新增黑门胜负入口、每日次数写入、通关共享事务和已有通知队列接口。胜利要求本场原始敌方门的死亡证据，失败要求原始友方门；每日次数与材料同事务，失败和成功不能对同一奖励 run 交叉领用。多人失败通知写入复制后的有界邮箱，后续通知追加仍使用原有 append 的容量检查，异常在提交前回滚。多人胜利沿现有 group_settlement 共用一个 writer，原始 actor 经 _giant_task_actor 传给 DailySpecialClear，避免把 shadow 当成在线身份。黑门新规则明确禁止普通首胜付费加倍。

地区变更复用已有掉落池和数值；制作沿用现有原生配方、材料扣除与产物事务，没有新增制作系统。作者 10 组测试和 53 个配方的相同输入结果可以复用，不再重复执行。但组队成功测试只覆盖共享 SQL writer，模拟了 typed admission，并未执行真实 group_settlement 的在线整条路径；不能记为组队实战通过。

发布时必须在恢复代码中保留新增 38300 日计数的读取能力和 dark_gate_failure_receipts，不恢复旧玩家库、不删计数回滚。尚未冻结恢复组合、安装或完成自然业务核收。下一步按既有发布流程准备候选；实际掉落、拾取、制作、胜负和次数显示继续依据线上玩家行为及服务端证据判断。
