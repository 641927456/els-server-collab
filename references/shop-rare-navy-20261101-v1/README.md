# 商城稀有版与海军礼包补货

修复普通版已售而稀有版未收录、海军特别版和沙滩床版缺失的问题。新增1630个角色／配色／露希侧别礼包，包含78个海军相关版本；保留每礼包50 ED的既有本服规则。28个仅有名字、没有稀有成员证据的幻龙降临父模板不开放。

固定包表与原生预览提供时装成员，`CharCustomData.PACKAGE_ITEM_ID`提供附赠定制书关联；新增44个永久定制书来源。通用饰品按当前角色适用，露希合包沿原有双侧发货。普通饰品仅将已核整包成员作为新增销售来源，其他仅供旧存档使用的饰品继续被拒。

`source/`保存正式运行基线的精确源码增量；不覆盖本仓库较早的根引擎。`bundle-membership.json`保存成员和来源决策；`source-contract.json`绑定双端8文件差异、私有载荷SHA及测试结果。静态资源、原生镜像、库和运行日志留在维护者私有工作区，不随Git提供。

1630个礼包已逐包验证扣费、完整发货、原请求重放和冷读；78个海军版本覆盖穿卸与原生单位读取，44个定制书来源覆盖礼包购买、登记、应用、重放和冷读。另验角色拒绝、满包、编码和中途成员写入失败回滚。3987个新增物品定义通过原生DTO与分类器，复用33434个未变定义的已有证明。

没有新增客户端Hook、修改原EXE/KOM或改变存档结构。尚无自然鼠标GUI验收。双端安装与源码提交状态另见交付记录；失败恢复必须保留新定制ID的读取与旧回执，暂停新购买，禁止恢复玩家或账号库。

国服历史礼包说明：[2024年7月10日公告](https://els.ztgame.com/html/news/134d944/004-1720-017fe-428091.shtml)明确水手泳装稀有版附额外上衣、发型，海军／水手沙滩床版附额外发型、动作。它证明历史实装内容；50 ED和永久直发属于本服已批准规则。
