# GM 高阶强化卷轴与角色升级卷轴

GM 物品目录原先没有 +11/+12/+13 强化卷轴和角色升级用的贤者的卷轴。现将 117534、117535、163313、710092 登记为可发放物品，并接通原生使用事务；不扩展活动、专用或直升99变体。

高阶强化复用221/222和已有装备资格、原子扣券、强化进度及幂等回执。升级券复用219的单张/批量数量、现有经验结算及21A/D9，同笔扣券、提升等级和存档；目标到相应等级经验门槛，拒绝超过99级整批请求，不改变转职、共鸣或经验倍率。原始每栈300。

`source-contract.json`记录两个实际父版、每个变更的前后SHA与安装清单；`source/common`为共享源码，`source/online`和`source/local`保留物品目录的模式差异。此目录采用现有运行源码归档方式，不将较旧main根目录发动机替换为不完整的新运行树。

已通过双端隔离SQLite事务、合法拒绝、回滚、当前状态重放、四种既有智慧药水回归、原生物品与D9解析、真实会话分派；正式线上通过GM搜索/发放、单张和批量升级、三档强化、余额拒绝和重新认证后的冷读。双端运行观察与启动器选载以合同验证记录为准。自有QA认证及注册名额已清理；玩家游戏存档保持。没有自然鼠标GUI或实战验收声明。

`validation`脚本是有私有资源的维护者在原任务目录运行的实际验证器；完整绑定、运行表、原生镜像和测试库未随Git提供，不能把缺少这些依赖时的未执行当成业务测试通过。正式版本与来源见合同，Git main合并另行审核。
