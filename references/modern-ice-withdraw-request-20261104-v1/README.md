# 百宝袋原生领取入口修复

原生领取按钮2EC5B90调用2EC8DE0发出BD3请求，并等待BD4回包。旧服务端误将BD4当作请求入口，真实界面发来的领取请求没有进入提取事务；此前只验证了map写入器DAEE70，协议夹具也误发了BD4。

修正modern_ice_flow.handle接收BD3，继续使用现有提取事务、BD4回包及历史回执类别。仅一份运行文件变化，保留全年销售期、赠品不计分、跨角色百宝袋和其他线上修复，无数据库或客户端格式变化。

新增原生发送器验证实际事件编号、请求头和多选payload；同一原生请求进入真实Application/session，验证两种背包类别的多选、部分数量和整组提取、跨角色开箱、重复请求、超量/满背包拒绝及编码故障回滚。旧入口确实忽略BD3，修复后通过。自然GUI未启动；本轮依据用户截图定位，线上安装另行登记。原生映像SHA见native-request-proof.json；私有样本和G盘基线不随归档分发。

verify_withdraw.py为隔离运行验证，依赖本项目G盘基线及原生样本；verify_contract.py只核归档源码和已有结果，不代替运行测试。已持久化BD4回执不改写，后续请求操作标识使用实际BD3事件。
