# 变量参数驱动的机关生成依赖修复

原客户端 AI 从表、闭包、整数／数字／向量槽位选择实体时，旧采集器漏掉合法 NPC 身份，使 2CE 被拒或初始化缺少所属模式 HP。此候选补齐 33 个副本／模式、235 处阶段生成依赖，新增 27 条初始化资料及 132 条精确模式 HP 绑定；公共采集器保留 NPC 枚举来源，避免把普通状态数值或布尔值当作模板 ID。

5 个运行数据文件及 2 个开发工具保存于 source，按实际最新父版 native-dungeon-skill-replacement-20261104-v1 核 SHA。此前父版之后的 15 个业务文件改动全部保留，原编排、过门条件、奖励及既有 HP 不变。与已测 fix-v3 候选的七个交付文件逐字节相同，235 项 DungeonRun 与双人 Application/TLS 成功结果复用；最新父版另过两条实际双人递归生成路径、客机拒绝、非法批次原子性和余额保持。240 个程序／480 条具体路径的独立生成式对照随便携测试提供。

六个原档缺失 Lua 名字已沿当前状态机和标志不变量复核，没有可执行生成入口；仍不声称恢复原 Lua。三个原无效枚举引用中，两处当前房间不可达；Henir 35870 的 12578 回调和缺失的 12582 来源仍是单独的客户端绑定边界，未猜替代模板，也未据此宣称玩家自然卡门已经复现。旧 GOD 模式的既有有限域保持，不扩展状态计数器、概率或 NPC 池。

执行 verify_contract.py 核精确数据／HP／阶段依赖和测试绑定；执行 test_flow_properties.py 核共享采集器的 CFG、类型及模板来源。repair 下保留在原私有分析布局中运行的采集／验证代码，原 KL、客户端及私有资源不随 Git 提交。检查通过不代表自然全副本通关、多人实战或完整结算已实测。

本目录为隔离来源归档，不激活根引擎，不自动安装。线上安装、本地／启动器交付及主干合并分别记录；本轮均未执行。后续发布由项目指定负责人核该精确候选及当时父版，保留其他增量和 LOCAL 差异。
