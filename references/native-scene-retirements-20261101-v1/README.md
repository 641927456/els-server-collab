# 原生场景退场接收修复

厄泰拉核心30302的Boss前343是原客户端的隐藏PD计时器。脚本自行SetNowHP(0)并经DYING_END发255退场，原服务器拒绝报告，关卡的key_code=1无法完成。本修复接收这一实际报告，原Boss338及其召唤与结算流程继续工作。

同类扫描覆盖260个准入入口、258份关卡图和10797个来源行；63个地图ID的117个来源卡点已通过原关卡条件复现。地图ID包含普通、剧情及内部变体，不等于63种独立玩法。修复在这些受影响地图内固定声明769个原生场景来源，覆盖前置和辅助控制器；每项核完整关卡图、脚本SHA、来源、原生类和初始化HP，未提供class103通配接收。5份缺少来源身份或初始化器尚不能解释的脚本未纳入。

组队优先进入现有共享入口，仅主控和当前完整成员可提交，同步准备全部编码、邮箱后才改变所有run。已有story/public来源沿用原资格、任务writer及同一SQLite事务，34320专用来源校验保留。归档精确5文件运行候选和已生效public_controller_rules依赖。仓库的历史/当前channel绑定root源码旧字节，因此保留这些旧绑定，把本批源单独按SHA归档；不把整棵root源码当正式服覆盖源。本批未修改current-engine选择。

验证结果：117项原条件打开，重复报告仅ACK、冲突拒绝；769项真实生成实例与4614项来源变异拒绝；12项隔离Application/SQLite场景成功，含厄泰拉单人/2人/4人完整协议路线、Boss召唤、结算冷读与重入，34350及33901换图，34090两人共享，四人末成员编码失败回滚和共享任务SQL回滚。早期失败来自测试邀请漏成员、ENTRY导入和编码器patch位置，已修正定向重跑；全库dump中不相关活动观察写入不作为本事务的回滚断言，实际核四张任务表、经济及run状态。

可重复定向命令：`python -B tools/check_native_scene_retirements.py --runtime <已核运行端根目录>`。该工具只读取已锁运行资产并把本PR归档的四个规则/接收模块载入验证；不声称验证整棵Git源码与现网全部差异。gate-cases.json是去掉运行日志和路径的有限回归输入。manifest绑定源码字节；静态数据仍走原锁定资产。

自然GUI/自然战斗、双端运行安装由发布负责人另行核收。当前源码参考不宣称已安装或已合并。没有数据库迁移、客户端支持文件变更或EXE/KOM修改。
