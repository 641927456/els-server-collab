# 选角前宠物远征定时刷新断线修复（Issue714）

账号只有UID1002等非默认角色时，尚未选角的root仍使用默认UID1001。原periodic先读取character()['level']，到后面才验证selected(s)，在characters_ready阶段抛Unknown character，连接被关闭，原生客户端随后自行退出。两次自有GUI失败已保留，未将其当成玩家手动关闭。

只移动一行：先复用原selected(s)确认已经选中的城镇角色，再读取等级。未选角、换场景和副本中的本条刷新不读取角色／不写远征数据；正常99级初始化、98级不初始化、同日去重保持。实际已选角色损坏仍抛错，未增加默认UID、伪造角色或catch-all吞错。

定向生命周期测试复现旧失败并验证修正后各阶段；正常99/98及当天去重以受控selected/storage返回核对，未冒称远征经济事务重验。真实自有客户端在未选角界面保持47.85秒，之后由人正常选角进入游戏，服务日志无notification_error。此GUI用例的追逐房进度另行调查，不在本修复验收范围。

source-contract.json冻结一个服务端叶，无客户端、存档结构或经济规则改动。实际发布负责人按当前父版选择性应用，保留后续增量及LOCAL差异。库、原始日志、截图和测试中途推进均不进入交付；候选、主干和实际双端安装分别登记。
