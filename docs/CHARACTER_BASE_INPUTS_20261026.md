# 角色基础成长输入（Issue539）

初始化和副本成员报文原先向所有角色发送同一组测试基础值，等级变化不更新这些输入。本次按用户2026-10-26明确批准的公开成长规则替换：1～99级HP为10000+1500×(Lv−1)，双攻为320+9×(Lv−1)，双防为80+2.25×(Lv−1)。武器浮动幅度单独由原生装备实例提供，裸装输入为零。

来源：[日文Wiki各種データ](https://wikiwiki.jp/ersword/%E5%90%84%E7%A8%AE%E3%83%87%E3%83%BC%E3%82%BF)的BaseHP、BaseStatus及初始职业表，2026-10-26重新核对；与锁定客户端的15个初始角色系数交叉核对。这是公开来源的兼容基础输入，不冒称恢复当前国服服务端原始表或执行了原生裸装成长函数。转职本身不额外增加裸装基础，被动仍由原生消费者处理。

仅改3个运行叶：配置、基础属性入口及新的独立来源校验模块。装备、时装、饰品、称号、套装、技能和效果继续使用现有原生输入/计算路径，基础报文不重复叠加装备估算。保留当前称号贡献与所有较新修复。无新表、安装DDL、客户端改动、物品来源或玩家存档迁移。

195职业与1/50/99级来源绑定、双端实际私有SQL升级/回滚/重放/冷恢复、当前原始角色DTO解析已核。自有屏幕外不可激活原生客户端已读到99级新裸装值；四件普通/影子鉴定、穿卸刷新及新进程冷重登通过，完整原生战力计算函数给出非零值。原生采样首次与另一已装载的观察器前缀检查冲突，保留失败后在同一自有客户端补只读观察，没有重放经济请求。

本PR不宣称完整战力缓存同步、全部套装/被动/条件效果、自然玩家伤害与多人战斗已验；独立战力缓存仍需沿合法通知链补齐。Git合并不等于生产安装，实际双端发布另有冻结回执。
