# 宠物与普通坐骑的多人状态通知

切换宠物A→B、取消宠物，以及普通坐骑上下马时，服务端补发带角色UID的原生2EE、42E、431通知。复用既有宠物完整DTO和串行轮询，核当前账号/角色租约、城镇或普通副本阶段；每个来源每轮最多只读一次。异常读取不丢弃接收方已经生成的其他通知，过期、离场及角色代次变化重新核定。

客户端继续负责显示、AI、攻击、效果和计时。无客户端改动、数据库迁移或新奖励来源；特殊变身坐骑和Raid/挑战模式没有因此开放。

本地受控事务、隔离双/三连接TLS、错误隔离及实际发布父版入口检查通过。正式服务端按双SQLite API备份、交付解释器检查和超过120秒观察发布；公网两个自有账号验证宠物A→B→取消、普通坐骑上下马的完整对端通知，并核冷登保存。QA使用受控GM物品来源，结束后账号停用；不代表自然获取、真实GUI或多人实战验收。

发布编号为`character-companion-alchemy-20261021-v1`，本PR只含其中伙伴同步的三个源码叶；Git主干按最小调用点整合，保留渠道差异。线上/本地/启动器的实际状态以各渠道正式指针及验收回执为准，合并PR不会触发部署。失败恢复只恢复代码，保留玩家库。
