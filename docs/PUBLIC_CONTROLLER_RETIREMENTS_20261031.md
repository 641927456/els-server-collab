# 公共副本退场与剧情资格分离

伊芙在双头蛇的神殿普通难度结束战斗后，盖亚进入原生锁血退场状态，服务端却没有确认控制器退场，因而没有进入通关结算。旧盖亚接收规则限定莉缇娅及特定剧情任务；同类公共来源还存在缺少接收或附带可选剧情资格的问题。

修复沿现有 `story_controller_retirements` 入口接收当前来源的原生通知，公共副本的结束条件与可选剧情任务资格分开。135 条有限来源覆盖大师之路 16 个普通／地狱入口，以及 34060、34090、34170、34180、34190。角色专属剧情规则、当前场景与实例、模板和源序号、图和脚本 SHA、HP 初值、会话归属、门的清怪要求、原延时、幂等和结算流程保留。未改客户端、经济数值或数据库格式。

这些规则依据当前图与已解码 `DYING_END` 脚本，以及既有未改原生 8009 的退场生产器／报文合同核定。没有取得本次玩家 Gaia AD 的原始正文，受控报文与同引擎来源等价证据不等于 Gaia 自然战斗抓包。
