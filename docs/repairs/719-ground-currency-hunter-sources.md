# 副本钱币外观与猎人箱子来源

普通副本的多个掉落入口以前固定发送铜币模板，导致金额增加后仍显示铜币。现在在新实例生成时统一选择外观：1～50 ED 铜币、51～150 ED 银币、151～1999 ED 金币、2000 ED 起金块。阈值复用已索引旧端 `KDropTable::GetEDItemID`，模板由当前客户端分别核定；登记为本服显示规则，不声称是最新官服公开分档。发放金额、加成、账本和历史实例保持原语义，旧铜币大额实例仍可领取。

猎人箱子复用当前准入 PvE 路线及精确 graph SHA，解除原五图范围限制，明确排除活动切换图和正式急袭经济来源。当前140条候选中，115条有既有生成条件要求的普通怪物位置；仅Boss或无有效普通位置的场景不强行生成。原五图固定来源仍保留供已有鱼饵分支使用。整局一次25%抽取、未命中记录、奖池、周次数、有效猎人、全员加载及原事务保持。归档、挑战图仍不能取得普通来源资格。

药水和装备按当前资源分别显示药瓶、材料袋和武器标识；自有客户端原生 CF 画面已核，没有复现全部变成同一模型，未新增客户端 Hook。原生2D0也已构造1615箱模型对象；不把预览当作自然战斗、网络领取或全部地图实战。

验证包括：7项可移植单测；私有SQLite的银币/金币/金块拾取、重放、旧铜币兼容、编码失败无增量及冷读；五档新普通来源生成、不重抽、来源变更、活动/急袭及特殊图拒绝；140条候选原图位置只读核查；新增30092箱子的生成、销毁、领取、周次数/经验、冷读及重放；原生金块20个成功序列化分支。实际Application/TLS黑暗森林13次拾取、结算与冷读3038 ED，34320双人154次拾取、每人2038608 ED并核全员事务回滚。证据摘要随 `references/ground-drop-models-20261101-v1/qualification.json` 提交；私有数据库、原始日志、客户端与进程镜像不入Git。
