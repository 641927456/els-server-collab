# 当前服务端架构与优化顺序

本轮以实际 `native-current-refresh-inputs-20261027-v1` / LOCAL 父版继续，包含两类永久票券和任务/转职刷新后继交付。`channels/formal-current-refresh-20261027-v1.json` 是完整引擎源索引；`channels/server-risk-current-20261027-v2.json` 在其上逐端仅叠加七叶。不使用旧 Clock 整树覆盖。当前父较 Clock 的十二叶增量逐 SHA 保留，宿主配置、客户端和玩家数据不入 Git。

## 已经做的调整

1. **可重建的双端源。** 完整源/规则/静态资源映射替代“根目录与若干归档由人猜组合”。文件丢失、资源不符或覆盖既有输出会拒绝。模式差异分别绑定。未来 root 修改若破坏冻结父源，CI 会拒绝；先将旧源原字节归档并更新来源路径，不能改旧冻结 SHA 来消除报错。
2. **减少高频无效工作。** LOCAL 活会话的原九字节辅助报文不再反复重建业务投影；活动时钟和独立到期/任务周期仍执行。线上原严格身份/租约守卫保留。
3. **减少账号读连接建立。** enabled 仍每次读取已提交值，只复用同线程只读 autocommit 连接；独立写者撤权立刻可见。没有跨请求权限缓存。
4. **把日志文件写入移出网络循环。** 有界队列和溢出计数保留排查能力，正常路径不阻塞文件/stdout。关键运行事件满队列时继续同步落盘，极端磁盘故障仍可能影响它们。
5. **测出队列和处理的区别。** 固定类/有界窗口统计、请求关联、连接锁等待、业务队列、投影、编码和 drain 分段。服务端 drain 不是客户端收到或显示完成，不能当成 RTT。

## 下一步优先改哪里

| 优先级 | 位置与当前问题 | 可行调整 | 必须守住的边界 |
| --- | --- | --- | --- |
| 1 | 每连接 50ms 周期提交，房间内还各自节流；多人会放大队列和重复读 | 先按 telemetry 统计空周期成本，再将到期工作按 deadline 和房间合并；通知按 mailbox 唤醒，保留关闭/禁用检查 | 不丢原生计时/到期，不跨连接重排回复，禁用仍及时生效 |
| 1 | 所有业务、GM、认证、周期共享单 worker | 保持事务命令单写者；将经测量的纯静态查询和只读 DTO 准备移到有界读取通道，回写者再核当前 UID/lease/revision | 不把共享 LocalSession 放进多个 worker，不返回过时经济/归属结果 |
| 2 | 新连接和大 DTO 触发重复投影/静态依赖 | 利用现有 committed-read/data_version 复用，依据 projection_loads/hits 收敛同一操作的重复取数；只缓存经 SHA 锁定的静态定义 | 业务快照不加跨请求 TTL；提交/外部写入仍使缓存失效 |
| 2 | LocalSession 与多条冷登录/任务/转职刷新路径很长，曾漏传称号/基础输入 | 随独立用例抽出 decoder、资格检查、事务命令、当前快照 serializer；优先统一已经证明等价的快照构建 | 场景通知/后置动作保持各自顺序，不一次改写整个 dispatcher |
| 2 | 大部分 SQLite 调用有 10 秒等待，慢写者会阻塞整个业务队列 | 先定位 registry/projection 与长 handler 的重合，再查具体 SQL 计划和写锁持有段；将冷静态工作放到 BEGIN IMMEDIATE 前 | 不统一缩短 timeout 造成经济重试，不给所有表盲加索引/DDL |
| 3 | 多人规模尚无自然样本 | 在最终部署版本收集首次/冷启动与单人操作的 P95/P99，再做隔离多账号场景；超过单核/队列预算后才考虑按房间分区 | 交易所、钱包、组队结算等跨房间事务仍需全局原子约束 |

当前没有引入新数据库、消息中间件或微服务；它们会增加部署、故障恢复和分布式经济事务成本，现有证据不足以支持这一步。

## 证据边界

Clock 同父的自有库受控样本中，100 次本地辅助调用 P95 3.553→0.133ms；1000 次 enabled 查询 P95 0.215→0.043ms，暖后每100次连接建立100→0。该对比不代表真实玩家端到端速度。

在最新角色刷新父上重跑90个定向测试，87通过、3个LOCAL专属在线上跳过。包括真实隔离TLS双账号、双方各128次辅助报文、库存读取栅栏、独立连接撤权、错误原生封套拒绝、角色快照、HP/Hero和事务/读取约束。旧全套副本/多人用例的未闭合资格和流程覆盖见 `CURRENT_RUNTIME_REGRESSIONS_20261027.md`，不冒称全量回归或自然战斗通过。
