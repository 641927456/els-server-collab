# 神物成长道具数量请求分派修复

用户反馈：[阿莉尔]神物升级卷轴无法使用。对应模板711317，与711315、711316、711318共享神物升级入口。

基线：`ee776b13512b3ec832a7fbc574b925c61098d6a6`。修改范围为`els_server/domain/local_session.py`的219请求分派顺序及相关回归测试。无客户端、配表、概率、经验公式或存档格式修改。

## 原因和修复

原生2260FD0/2224DE0的219消息将使用数量放在第二个uint64，0代表普通点击使用一张，显式1和批量数量都合法。现有神物解析器和事务已经支持该布局，但排在共鸣书、定制书、原力书之后。前面的通用`career_messages.use_request`把第二字段作为目标UID，遇到非零数量提前抛错，神物入口未执行。

将已有神物消费者移到219业务分派最前。它先按自有物品或已有回执识别神物道具，再解析其数量；非神物返回None，继续原来的分派。仍复用既有升级、阶段限制、扣物、持久化、回执重放和904同步。
