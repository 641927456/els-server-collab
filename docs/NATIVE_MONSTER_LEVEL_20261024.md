# 副本原生怪物等级输入

当前固定等级副本沿用同一spawn seed，遗漏当前源表的m_NPCLevel，导致发送给原生消费者的等级未随副本改变。本项仅填已有资源+0x0C到DTO+0x53的等级字节，使用锁定路由正整数等级及三条已核编译LEVEL覆盖，不增加客户端计算。

原图/source SHA、stage、part、source_index和template共同限定覆盖。255张已核固定等级图的9927个实际actor仅等级字节变化；三个活动图、缺原等级38300和相对玩家等级120010共105个actor完整报文保持。原HP、初始化属性、其余DTO、实例、阶段、死亡和奖励路径不变，无数据库迁移。

全部路由对照及双渠道真实Application私有TLS检查通过：30282、33202、34320分别收到36、69、99级输入；验证未发送死亡或奖励请求。静态源及编译LEVEL证据已单独冻结并由独立作者审查。未将这些检查写成自然GUI或多人战斗验收。

怪物HP曲线和掉落绑定仍有独立待核范围，本次不据旧占位数值推算，也不扩大掉落来源或概率。双渠道实际发布状态以维护者正式指针及冻结回执为准；Git提交和PR不自动安装。
