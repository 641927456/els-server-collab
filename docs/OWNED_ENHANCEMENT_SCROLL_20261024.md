# 现存强化卷轴的原生使用

此前仅有普通强化5FF，未处理卷轴221，因此对装备使用已持有卷轴没有222回执。本项接通原生双UID请求及完整库存回执，严格限定130149/130150/130151/130152四张，分别提升到+7/+8/+9/+10；只允许当前等级严格低于目标、未穿戴且未破损的普通装备。

保留当前账号、选角代次及有效会话、UID归属、过期和锁定检查。一次真实SQL事务只扣一张卷轴，不扣ED，不新增来源或强化概率；原生效果继续由客户端执行。更新等级后沿既有规则清旧等级进度，低于12时保留已有保证点。完整222编码先于回执和提交；编码/资格失败全部回滚，旧请求重放返回当前实例和原槽当前占用者，不恢复旧等级、旧位置或消耗。

四种当前源规则仅含ID和ENCHANT_LEVEL。另五张带ENABLE_TRADE字段的候选因服务端语义未闭合而保持拒绝且不消耗，其他静态卷轴不因此开放。旧候选及源资格审查轨迹保留。

双渠道各28项真实Application/私有TLS及受控SQL检查通过，包括四张成功、五张保留拒绝、较高等级/穿戴/破损/锁定/过期/跨账号/失效会话拒绝、预编码回滚、移动后的当前回执与冷登。各475加载模块与父包或候选逐SHA核定；独立补审通过。没有客户端变化或安装DDL，原存档不迁移。自然GUI和公网QA状态另以维护者实际回执为准。
