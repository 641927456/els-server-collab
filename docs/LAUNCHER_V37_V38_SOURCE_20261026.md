# V37 / V38 启动器源码同步

两版完整、独立的原始编译源码分别在 [V37](../launchers/friends-v37/README.md) 与 [V38](../launchers/friends-v38/README.md)。每版包含全部 C#、manifest、公开签名成员清单、逐文件冻结 SHA 和可移植构建入口；V38 另保存内嵌 Python 安装器。图片和图标沿用已锁定私有资源附件。

V37 提供本地/线上模式选择、Git 源码快进及界面动效；V38 在此基础上提供本地服务端一键检查、双库备份和安装。两者仍共用原生程序/启动核心，保留模式偏好、密码和签名更新。历史 EXE 摘要及合格发布证据分别绑定在 release.json，不将源码归档当作新部署。V38 真实一键安装的120秒观察、账号和存档保留已另行核收；实际较新业务被保留，没有重复替换业务文件。

协作 main 是源码视图，V38 的本地更新通道使用 updates/local-v38；[通道登记 PR493](https://github.com/641927456/els-server-collab/pull/493) 与本次完整实现归档分开。这里不修改当前线上、本地或启动器指针，不发布新的 EXE，不把 Git 推送等同服务安装。

原始源码从已发布冻结目录逐字节核定后导出，未修改其运行行为。维护脚本仅增加便携输入核验；仓库隐私守卫为两条精确 Program.cs 路径沿用既有随机自测前缀例外。两条 ModeDesign.cs 的模式隔离自测含明确的非机密 dummy token，仅按已核完整文件 SHA 允许该单个字面量；任何文件改动或其他凭据仍拒绝。私钥、私有状态、原始发布/验收日志和账号存档不随本项入库。
