# 原生零现金余额查询（2026-10-21）

当前服务端使用 ED 商店策略，原有 1B2 查询已经返回 1B3 的29字节零现金余额。当前 DX11 的原生生产者只发送空请求体；服务端此前忽略额外请求体。本项仅在原分支拒绝非空请求，原零余额回包、阶段范围和旧客户端行为保持。

客户端继续使用原有余额消费者和界面。未增加充值、现金账本、非零现金授予、现金消费或 ED 转现金；不把此项描述为完整现金业务。B71/B72 强化配置已有独立实现，本项不重复添加空成功路由。

来源：匹配构建的已有生产者/消费者恢复结果，以及12份已核完整性、MAC和空请求体的历史原生捕获。原始抓包、客户端指令镜像和账号数据不进入仓库。2014服务端仅交叉核对协议语义，不套用旧区服现金枚举或余额规则。

验证：两套正式父版各通过实际私有 TLS，覆盖自有选中角色、两个不同非零 ED 账号的零现金查询、重复请求、断线冷登和非空请求拒绝。查询前后私有数据库结构与全部原行保持。首轮夹具连接未关闭导致的 Windows 临时文件清理失败保留；修正夹具后通过，业务源码未变。已有服务端忽略额外 UID 并返回静态零，不等于已经发生跨账号泄漏。
