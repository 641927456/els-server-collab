# 按客户端版本隔离旧 B6F 请求（2026-10-21）

旧客户端的空 B6F 请求与 B70 三容器响应不能直接用于当前 DX11。同版已有生产者/消费者证据表明，当前 B6E 携带一个 int 发起请求并等待 B6F；B6F 已用于CustomEvent整数状态回包。当前服务端却仍将入站 B6F 解释成旧请求并返回 B70。

本项只在原旧分支对当前 DX11 拒绝该入站请求，保留 legacy 的 B70 原回包和原阶段范围。没有根据旧包号造当前活动、奖励或配置；该CustomEvent业务的规则、正常来源和完整事务未闭合，继续保留未实现边界。现金余额查询是另一独立修复，本PR不包含其hunk，也不依赖该PR。

测试区分两个层级：当前 DX11 通过真实私有 TLS 验证旧请求不再收到 B70，协议错误仍报告，阶段、已完成集合和临时双库结构/原行保持；legacy 只验证受控原处理器的字节兼容，不冒称旧版真实客户端或网络验收。

不新增客户端 Hook、效果、界面、计时、数据库迁移或启动器改动。源恢复结果和历史捕获只引用必要语义/哈希，原始游戏镜像、抓包、账号、密钥和运行日志不上传。线上已安装 `cash-auxiliary-contract-20261021-v6`，正常停服、双库 API 备份和120秒观察通过；公网受限自有 QA 的只读组合验收通过，其他账号原行、配置及库存/ED/回执保持。初次初始化因历史 QA 账号不存在而阻断，未发送游戏请求；随后按受限管理流程建立一个自有 QA 账号和一个角色完成验收，用后禁用。原账号标识、日志及完整回执不进入 Git。正式本地已独立备份安装 `local-cash-auxiliary-contract-20261021-v6`，双库 API 备份、全部文件 SHA 核对和121秒观察通过；自然玩家 GUI 未新增验收。本 PR 仍仅含本项独立 hunk；线上 v6 是两项经独立审查的 guard 组合，仓库源码视图不代表完整正式运行快照。提交不自动部署。

验证：`python -B tests/test_legacy_auxiliary_direction.py`。需要锁定协作运行资源和测试证书依赖，只操作临时库、独立世界和环回监听。

适用边界为当前普通服务端策略：零现金查询及旧请求方向校验。本项不开放充值/现金账本或未知 CustomEvent 业务，也不代表账号与基础整卡或自然 GUI 已100%完成。
