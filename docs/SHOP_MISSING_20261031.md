# 爱心瞳及普通时装礼包商城补齐

Issue #692。旧选择器把共用 `IceHeaterPreView` 的全部奖励当成冰装，导致纯粹假日等普通时装礼包被排除；爱心瞳部分角色则因旧销售标记缺少商品与永久书登记来源。

候选补充1,971个完整礼包（含全部32个纯粹假日普通礼包）、13个爱心瞳书（共17版本），同时恢复5件已具商城来源的普通饰品。现有50 ED本服售价保持，真正冰机奖励继续排除。缺少PackageItemData的4个普通纯粹假日礼包采用明确的本服六件套成员，来自对应原生预览，不含另一套发型／上衣，不引入随机池或概率。

共享商城按原生角色字段过滤扩展商品，错误角色不能购买。露／希尔旧根书接受原生根编号，并仍按现有映射登记两个侧编号；原有角色资格、原子扣物、幂等和冷读保持。本地同步已有授权及验证的866件一件套，其他停售定制与原有散件选品限制不扩大。

双端精确源码、资源SHA和验证摘要见 [source-contract](../references/shop-missing-20261031-v1/source-contract.json)。源码位于该目录的 `source/common`，本地一件套依赖另外绑定。主干根引擎与已部署引擎有其他版本差异，因此本次沿用仓库的精确源码归档方式，不整树覆盖或暗中激活旧根引擎。物品原始定义和原生证明留在私有增量包，Git只保存SHA和来源，不上传玩家库、凭据、日志或原游戏文件。

验证包含：新增13,160条定义的原生私有读取；1,971个礼包逐项购买／扣费／重放／冷读，32个纯粹假日六件套共192次真实穿脱和原生角色读取；17本爱心瞳购买、登记、应用、原生通知及冷读；编码与SQL失败回滚、错误角色／来源、余额不足和背包满拒绝。本地完成目录与实际购买、登记使用及5项一件套来源边界验证。自然鼠标GUI与线上实际核收尚未执行，不把候选或源码提交标成安装完成。

安装后已有新CustomID及回执必须继续可读；必要时暂停新上架／写入并保留新读者，不恢复玩家或账号数据库。双端安装及启动器组件核收由项目指定发布负责人按届时实际父版选择性整合，安装状态另行登记。
