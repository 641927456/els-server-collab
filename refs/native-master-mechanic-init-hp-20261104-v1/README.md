# 领导者机制对象初始化血量修复

丹尼弗、索雷斯及眷属地狱的8个护盾、锁链和光球模板缺少精确HP条目，生成时落入约11.97万的普通怪估算。这里在原共享血量表补齐CoboDex同图、99级、难度0的数值，覆盖2个静态护盾实例和8条动态模板。

仅归档formal_npc_hp.json及其manifest两份精确运行数据，基于source-contract.json记录的实际安装父版；血量消费者来源见PR #841。本仓库根引擎不自动激活。其他Boss、原生AI、护盾及退场回调、数据库格式保持原状。

双端各15项受控测试、网站原getHP纯函数16项复算通过。线上实际文件、120秒观察、公网5图静态/动态初始化及双人相同报文广播已核收，自有QA已清理。此轮只安装线上，本地未安装；自然GUI及战斗未验。

运行verify_contract.py验证两份数据、8项HP、SHA及脱敏证据。Git提交、主干合并与线上安装分别记录；本PR不执行自动部署。
