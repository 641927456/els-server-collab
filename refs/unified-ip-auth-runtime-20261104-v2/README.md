# 统一本地与线上认证服务端及签名运行组件

Local and online used separate authentication, session, seed-character and runtime selection paths.

Use the same authenticated TLS server and signed default runtime; local IP127.0.0.1, independent existing stores retained; native adapter127.0.0.2 avoids a same-port collision.

本目录为精确源码归档，不激活主干根引擎，不自动部署。source-contract.json固定源码和脱敏证据。运行 python -B verify_contract.py 核SHA与语法。

统一运行包按IP连接两端，账号、存档、证书各自保留。四项独立成果分别提交；最终V77源码按统一归档中的composition.json合成。未变资源从锁定签名组件取得，本目录不放第三方二进制、玩家库、凭据、原始报文或运行日志。自然GUI和实战未据协议验证冒称完成。

先行V76在用户追加成果前已推送；整合后以V77向前交付，确保已发V76满足更高版本自动更新条件。仅AutoUpdate.Version从76改为77，统一运行包和其余已验UI/业务源码不变。

三个历史批处理入口已统一转发到当前启动器，分别保留本地、线上和选择模式。source目录保留精确入口脚本；evidence/installed-validation.json记录双端实际安装和旧版清理结果。两端仅目标IP及私有存档、账号、证书与配置路径分别设置，本地保留原有六角色。
