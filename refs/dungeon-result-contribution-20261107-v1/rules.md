# 本服副本结算规则 v1

用户本轮授权：先查原版公式，缺资料时按游戏功能和玩法设计本服规则。此授权替代本任务先前“只还原原版”的限制；下面的权重、阈值、战力基准、平分和10%奖金明确属于本服设计。

原版已证部分继续保留：MVP按贡献而非字母评级；破坏比较总伤害＋攻击支援，守护比较减伤，恢复比较HP＋MP；各单项至少1点才授奖；单人成功通关固定MVP；多奖只发一份奖金。官方已核说明没有给出贡献系数、字母阈值及奖金比例。2022改版后的字母评级不直接改变奖金。

贡献分按队伍实际有效数据分配100分：输出70%、减伤10%、队友HP恢复5%、队友MP恢复5%、提供给队友的有效CD减少/加速10%。某项全队为0时，该项权重不参与分母；其余权重按比例分配。输出使用自身伤害＋给队友的攻击支援，避免队友给自己的增伤再次记成自身能力；恢复用于贡献时扣除自身恢复，单项“恢复”奖仍沿原版总恢复条件。每项按本人UID读取，CD沿已核recipient归属求和，观察者副本不相加。贡献量化到0.01分，MVP取最高贡献。

入场冻结服务端角色与装备提供的物理／魔法攻击较大值作为本服战力基准。它是已可核的服务端基准，不冒称客户端包含全部被动、套装和动态效果的完整原版战斗力。预期贡献份额＝个人基准／队伍基准之和，评级完成度＝个人贡献份额／预期份额×100。达到100/90/75/60/45/30/15/0分别为SS/S/A/B/C/D/E/F；MVP不按此完成度排序。单人有有效贡献时完成个人全部份额为SS；有有效报告但无贡献为F，缺报告为NONE而非伪造统计。承伤不扣分，通关耗时不参与评分。

四奖各取一人。精确单项平分或贡献分平分时，以服务端本局UUID、奖项类别和角色UID的SHA256排序，取最小者；同局断线和重试不重选，不优待队长或固定旧角色。

成功通关且至少获一奖，增加正常通关结算ED和EXP的10%，向下取整，只发一次；多个奖不叠加。奖金在已有倍率与称号效果之后、独立随机任务奖金之前计算，随后沿原ERP／等级上限和存档事务处理。不放大怪物击杀奖励、地面拾取、道具、神器EXP或其他任务奖励。失败、未完成的战斗和单独9E报告不能发奖。原完整通关校验不变，奖金仅由原权威通关writer原事务发放；最大增量固定为该次结算的10%，不随客户端报告的分数数值增长。

排名、奖项、规则版本及奖金明细随原reward_title_receipts.effect_json一起保存，C1在同一事务中写入对应原生字段。旧回执原样重放，不补发奖金；新回执重放沿第一次已存结果，不重算、不重奖。继续复用原C1解码和原详情控件，不修改EXE/KOM或增加产品Hook。
