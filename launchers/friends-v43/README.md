# 统一启动器 V43 候选源码

本目录归档实际编译的公开源码、签名清单和来源元数据。构建输入25项，运行资源7项；原 friends 1764组件保持。外部美术依赖沿用 build-assets.lock.json，不包含客户端、启动器EXE或任何玩家库、私钥。

`python build.py --check-only`核对全部构建输入；带锁定美术包的构建只编译，不签名或发布。此源码不包含游戏窗口输入或新增游戏Hook。
