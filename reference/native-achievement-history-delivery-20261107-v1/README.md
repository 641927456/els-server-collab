# V93 业绩历史交付候选

在 V92 基础上，只更新三个业绩业务文件与三个派生启动器源文件／签名清单。新增七类历史来源，累计21类、136条定义。53组原奖励继续查证并暂缓发放；其余39类来源、踢人／解散业绩语义和自然GUI保留待办。当前尚未安装，线上进度仍按已安装V92记录。

实际编译V93经过原有组件更新器验证，从V92只更新三个组件，2873个签名组件逐项匹配，重复检查下载为零；编译资源、内置签名清单与派生哈希均通过原有读取器验证。ModeDesign.cs、LocalMode.cs和Program.cs与V92字节相同，继续复用已核隐藏服务器IP的面板。原游戏EXE／KOM及Hook没有变化。

本目录保存未来公网／本地共用的有限自有QA夹具和请求场景，以及在实际签名选择目录中启动Application/TLS后通过的结果。场景验证真实扣币、扣卷轴、使用导师药水、公会创建／邀请／加入、正常退出与踢人区分、公告栏发帖、领地种植和收获，重复失败不增加计数、缺原奖励不发奖、账号共享和角色展示独立。所有临时私有账号、库、证书和日志已随隔离目录清理。

整合测试器最初发生同名导入旧场景和旧夹具的问题，已固定到本批模块后通过；生成验证脚本时的目录层级错误被断言阻止并修正，未影响生产。此前各业务测试的失败与修正说明保留在前两份来源归档及原分析目录。这里的私有TLS通过不代表自然GUI、原生Game或线上安装通过；实际安装后另补交付结果。主干未合并，不使用管理员绕过。
