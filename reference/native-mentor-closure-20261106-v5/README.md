# 原生师徒候选 v5

本版包含 v1 的师徒关系、寻找与召唤、组队经验/疲劳、14 项任务、奖励使用、转职证明及出师闭环，并补齐原生设置与冷登资料。原生2F第8个设置字节控制师徒邀请；原来的全零数据使游戏在同意前自动拒绝。完整10项167/168设置现在按角色原子保存，重登恢复，服务端尊重师徒拒收选项。其他未保存选项保持原值。

好友与师徒共享同一原生登录包：沿现有好友投影入口在同一 SQL 快照构造伙伴与好友/分组资料，保留其他字段。已通过原始完整2F解码、原生伙伴复制、全部1024种设置的原生读/写、168字段赋值及真实TLS保存/失败回滚/冷登。

原始游戏验收使用一个隔离教师Game与一个明确标注的协议徒弟；复用同源v6已通过的原生邀请/回答，继续使用其私有隔离存档验证冷登及原始720后直接227的实际跨城召唤，125秒到达后观察。观察器只读状态，并从原生回调调用原生接受/召唤同意函数；无鼠标键盘、焦点或HP覆盖，原EXE/KOM及签名支持组件未改。v6整个场景因缺目的地通关资格失败，原失败不改标；之后只补隔离输入并复用存档，不重建账号或重领奖励。冷登观察器加载时序的失败留在工作区，不冒称自然GUI或双原生实战。

42个服务端差异文件、16个新文件。此前有限业务结果按未变部分复用，旧225召唤用例由原生直接227用例替代，新设置及共享初始化执行直接相关回归；准确证据与边界见review-verification-v5.json和final-source-binding-v5.json。

当前仅提交隔离源码候选。未安装、更新启动器、合并main或更新线上进度。发布仍需性能会话最终交接、安装器保留已有GM/活动配置的修复审查及最终父版整合。其他未闭环功能组继续处理。
