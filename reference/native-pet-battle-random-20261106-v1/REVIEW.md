# 差异审查

入口只接受当前认证角色拥有的3只不同、无期限完全体宠物，排除远征、家园和VIP宠物。成长和属性在开战时冻结，战斗引擎不使用客户端伤害上报。回合使用副本计算并在所有回包编码成功后发布；超时结算复用同一发布入口，原生结果记录末尾携带另一方当前宠物UID，避免濒死替换后模型缺失。

两个原生无攻击碰撞接收器复用共享NPC初始化。其有限浮点容量用于保持原生受击回调，宠物战斗HP、伤害及任务结算来自独立服务端引擎，NPC容量不进入奖励或角色属性。重复34A确认由现有宠物房间消费，避免落入普通PvP路由。

最终两方动画ACK后，胜负事实、账号周进度、所有通知在一个SQLite事务中校验并封存；提交后只发布已准备内存状态，不再执行可失败的原子性假检查。邀请码模式预留字段不计周任务。兑换复用共享材料事务，先扣当前未锁定证明，再以相同事务内精确配方来源发物，编码失败整体回滚；历史回执只同步当前库存，不重新扣发。

最高级魔法石沿现有镶嵌预览/应用流程增加一个配表，RNG上界取实际权重总和。旧分布总和仍为10000且逐项保持；新分布穷举所有1092/336个整数输入，类间及类内严格等概率。现有装备选项、其他石头概率和存档格式不改变。新读取定义与获取许可分别处理，疲劳药水没有开放泛用来源。
